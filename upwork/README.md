## Record Upwork video

1. Open `deck/datumlabs_no_cases.html` (shorter) or `deck/datumlabs.html` (with case studies)
2. Press **F** → fullscreen
3. Loom: Screen + Camera (bubble bottom-right)
4. Script: `script/datumlabs.md`
